# APEX GT — 360° Interactive Car

Single-page 3D car configurator built with Three.js (r160), GSAP and ScrollTrigger.

## Files
- `index.html` — page layout and styles (open in a browser)
- `app.js` — procedural car model, camera controls, scroll journey, configurator

## Run
Open `index.html` in a browser with internet access (Three.js and GSAP load from CDNs).

## Notes
- The car is procedurally generated; swap in a Blender GLB for a production model.
- Specifications shown on the page are placeholders.
